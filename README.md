# IPL Data Analytics Dashboard

An interactive IPL analytics dashboard built using Python, Pandas, Streamlit, Matplotlib, and Seaborn.

## Features
- Top winning teams
- Top run scorers
- Toss impact analysis
- Season-wise trends
- Interactive team filtering

## Tech Stack
- Python
- Pandas
- Streamlit
- Matplotlib
- Seaborn

## Run Locally

```bash
streamlit run app.py
